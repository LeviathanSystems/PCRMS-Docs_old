User Dashboard

User Dashboard

The User Dashboard provides a centralized view of all users in your Leviathan PCRMS system. From here, you can view, search, and manage user accounts efficiently.

Overview

The User Dashboard displays all system users in a table format with key information at a glance. You can quickly see user status, contact information, department assignments, and recent activity.

Dashboard Features

Search Functionality

Located at the top of the page, the search bar allows you to quickly find specific records by:

  • Name
  • Email
  • ID
  • Other visible fields

Simply type in the search field and the results will filter automatically in real-time.

Create New User

Click the “CREATE NEW USER” button (gold button in the top right) to add a new user to the system. See Creating Users for detailed instructions.

User Table Columns

The dashboard displays users in a table with the following columns:

Column Description
Status Indicates if the user account is active (checkmark ✓) or inactive
ID Unique identifier for each user
Name Full name of the user
Email User’s email address for login and communications
Phone Contact phone number (may be empty for some users)
Department The department the user is assigned to
Tags User roles or tags (e.g., “active”)
Last App Login Timestamp of the user’s most recent login
Actions Quick action buttons for managing the user

User Status Indicators

  • ✓ (Checkmark) - Active user account
  • Empty/No checkmark - Inactive or disabled account

Active users can log in and access the system, while inactive users are locked out.

Action Buttons

Each row has action buttons on the right side:

  • Edit (Pencil icon) - Modify user information
  • Settings (Gear icon) - Configure user settings and permissions
  • Delete (Trash icon) - Remove the user from the system

⚠️ Delete with Caution: Deleting a user is permanent. Consider disabling instead of deleting to maintain historical data.

Pagination

At the bottom of the table, you'll find pagination controls:

  • Rows per page - Set how many records to display (default: 30)
  • Page indicators - Shows current page out of total (e.g., "1-1 of 1")
  • Navigation arrows - Move between pages when you have multiple pages of records

You can adjust the number of rows displayed per page using the dropdown menu.

Table Features

Sortable Columns

Click on column headers to sort the table by that field:

  • Sort alphabetically by text fields (Name, Email, etc.)
  • Sort numerically by ID or number fields
  • Sort chronologically by date/time fields

Click the same header again to reverse the sort order (ascending/descending).

Filtering

Use the search bar to filter users based on any visible field.

Tips & Best Practices

Tip

Quick Search: Use the search bar to quickly locate users instead of scrolling through pages. You can search by any field including ID, name, or email.

Info

Status Management: Regularly review user statuses to ensure inactive employees are properly disabled to maintain system security.

Warning

Delete with Caution: Deleting a user is permanent. Consider disabling users instead of deleting them to maintain historical records.
